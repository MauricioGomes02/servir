# Exemplos conceituais

Esta pasta receberá exemplos mínimos depois que os contratos das primitivas forem estabilizados.

Exemplos devem:

- demonstrar uma única relação arquitetural;
- usar nomes do [glossário](../glossary.md);
- evitar framework e infraestrutura;
- deixar claro o que é exemplo e o que é API pública;
- acompanhar testes quando se tornarem executáveis.

Não criar aplicações de demonstração completas nesta fase.
